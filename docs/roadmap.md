# Roadmap

Ideas, not commitments. PRs and issues welcome.

- Add more import format options.
- Warn the exporter when a product's variants store different attribute names, because a reimport gives every variant every name.
- Make the preview table editable, so a merchant can correct one title, SKU, or price before generating.
- Add a Products index action that moves the chosen products' variants from one attribute to another, such as `Size` to `T-Shirt Size`, with a preview before it writes. The variants keep their IDs and SKUs, and the source options stay for the variants outside the selection.
- Add GraphQL support.
- Add multi-store support.
